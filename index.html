☁ Cross-Device Sync

PC ↔ Phone

Supabase is your shared cloud save. Save Connection only stores the connection details. It does not upload anything. Use Push Local Save to deliberately make this device's save the cloud copy, or Pull Cloud Save to replace this device's local save with the cloud copy.

Not connected

Recommended first-time setup

  1. On the device that contains the progress you want to keep, enter the URL, key and Trainer ID, then press Save Connection.
  2. Press Push Local Save once. This creates/updates the cloud copy.
  3. On your other device, enter the same details and press Save Connection.
  4. Press Pull Cloud Save. This downloads the good save onto that device.
  5. After both devices have the same save, changes will auto-push after a short delay.

Important: Pull replaces this device's local save with the cloud save. Push replaces the cloud save with this device's local save. Saving the connection itself never overwrites either copy.

Supabase setup

Use your Project URL without /rest/v1/ and use the publishable/anon key, never a secret/service-role key. The SQL for the trainer_saves table and RLS policies is included in README.md.
