# Russ's Pokémon League Game

A standalone PWA life-game.

## Run
Open the folder in VS Code and use Live Server on `index.html`.

## Publish
Upload all files to the root of a public GitHub repository and enable GitHub Pages from `main` / root.

## Game rules
- All eight badges progress at the same time.
- No manual badge unlock.
- Badge levels: 20, 40, 60 points.
- Level 3 awards the badge item.
- Six Pokémon begin at their starter stages and evolve with Trainer levels.
- Garchomp, Hydreigon, etc. are end states, not starting states.
- XP is general progression; badge points are domain progression; coins buy pre-defined real-life rewards.
- Progress is stored locally in the browser. Export backups.
